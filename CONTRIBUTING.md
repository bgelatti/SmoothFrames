# Contributing

Thanks for your interest in Smooth Frames.

- **Issues are welcome.** Use the bug report or feature request templates. For bugs, attach `BepInEx\LogOutput.log` and list the other mods you have installed.
- **Pull requests are not accepted.** This is a single-maintainer project and the code is not open source (see [LICENSE](LICENSE)). If you have a fix, describe it in an issue instead.
